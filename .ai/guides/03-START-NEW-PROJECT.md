# Start a New Project

## Discovery

1. Define users, problem, desired outcomes and explicit exclusions.
2. Record security, privacy, legal, safety, cost and compatibility constraints.
3. Separate product requirements from implementation preferences.

## Foundation

1. Complete `PROJECT-CONTEXT.md` and `01-CONTRACT.md`.
2. Propose the initial solution boundary and component responsibilities.
3. Document critical business rules and state transitions.
4. Decide ADRs that constrain the first implementation.
5. Define repository commands and quality gates once the scaffold exists.

## First vertical slice

Choose one small end-to-end user outcome. Create a feature specification and task. Implement input, validation, decision, state/persistence and output only as required for that slice.

Avoid designing every future component in advance. Add durable documentation when a real decision or implemented truth exists.
