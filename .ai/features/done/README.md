# Færdige use cases

Denne mappe indeholder use cases, som har en tilhørende implementeringstask med status `Done` og derfor ikke længere skal ligge blandt de aktive use cases.

## Done

- UC-01 – Føre en naturlig AI-samtale
- UC-02 – Føre en sammenhængende samtale
- UC-03 – Vælge datakilder og tools automatisk
- UC-04 – Håndtere manglende eller usikker viden
- UC-26 – Betjen VICO med stemmen
- UC-34 – Deploy Roadcue til Azure
- UC-36 – Sæt aktiv destination
- UC-37 – Registrer chaufførens aktuelle GPS-position
- UC-40 – Oplæs VICO-svar med Azure Speech

## Regel

Flyt først en use case hertil, når den tilhørende task er implementeret og markeret `Status: Done`. Use cases med task-status `Ready`, `Planned` eller uden afsluttet implementering bliver i `.ai/features`.
