# Tværgående acceptkriterier

- VICO forstår naturligt sprog og kræver ikke faste kommandoer.
- VICO bevarer relevant samtalekontekst.
- VICO vælger tools automatisk, men bruger kun godkendte tools.
- VICO tilgår ikke databasen direkte.
- C# ejer SQL, forretningsregler, autorisation, geoqueries og præcise beregninger.
- VICO opfinder ikke Roadcue-data eller aktuelle realtidsoplysninger.
- Communityoplysninger har synlig sikkerhedsstatus.
- Skrivehandlinger valideres og bekræftes.
- Resultater er korte og egnede til oplæsning.
- Centrale funktioner skal senere kunne gennemføres uden skærmbetjening.
- Brugeren kan afbryde, stoppe eller annullere.
- Lokationsbrug kræver samtykke og følger brugerens delingsregler.
- Roadcue rådgiver chaufføren og styrer aldrig køretøjet.
- POC'en kan testes med simulerede chauffører og positioner.
- Eksterne leverandører ligger bag udskiftelige C#-interfaces.
- Første POC er reaktiv; proaktivitet implementeres senere.
