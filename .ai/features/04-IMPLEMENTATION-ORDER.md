# Implementeringsrækkefølge

Arbejdet gennemføres som fem leverancer:

1. **Tekst-POC:** samtale, kontekst, toolvalg og Friends-integrationen.
2. **Nyttig chauffør-MVP:** voice, steder, trafik, ekstern ruteændring, beskeder og vennernes aktuelle kontekst.
3. **Community-kerne:** frie observationer, aktuelle advarsler, Ask the Road, sociale pauser, oversættelse og relevante proaktive hændelser.
4. **Nice to Have:** udvidet companion, personlighed og Driving Coach.
5. **Datavision:** automatisk registrering og trafik-/parkeringsprognoser, når datagrundlaget findes.

En use case flyttes ikke frem, alene fordi den er teknisk spændende. Den flyttes frem, hvis den dokumenteret sparer tid, reducerer skærmbrug eller forbedrer aktuelle beslutninger.
