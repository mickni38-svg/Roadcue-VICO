# Roadcue use cases

Denne mappe indeholder Roadcues prioriterede use case-katalog opdelt i én fil pr. use case.

Start i `00-USE-CASE-INDEX.md`. Copilot skal kun indlæse den use case og de arkitektur-/domænefiler, som den aktive task kræver.

- `01-CATALOG-CONTEXT.md`: formål, afgrænsning, aktører, faser og prioriteret roadmap.
- `02-RELATIONS-ROADMAP-AND-ACCEPTANCE.md`: relationer, implementeringsrækkefølge og fælles acceptkriterier.
- Domænemapperne: 33 bruger-use-cases og 6 understøttende system-use-cases.

Use case-filer beskriver varig funktionalitet. Konkrete implementeringer styres fortsat gennem `.ai/tasks/`.
