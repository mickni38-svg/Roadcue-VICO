# Roadcue use cases

Her ligger Roadcues varige produktadfærd som én fil pr. use case.

## Brug kataloget effektivt

- Kender du stien til en use case, så læs kun den fil.
- Kender du kun ID eller domæne, så brug `00-USE-CASE-INDEX.md`.
- Læs roadmap, relationer og fælles acceptkriterier kun når opgaven kræver dem.
- Opret implementeringsarbejde i `.ai/tasks/`; redigér ikke en use case for at registrere en konkret kodeplan.

## Katalogfiler

- `00-USE-CASE-INDEX.md`: alle stabile UC-/SUC-ID'er og filstier.
- `01-PRODUCT-SCOPE-AND-ACTORS.md`: formål, afgrænsning, aktører og faser.
- `02-PRIORITIZED-ROADMAP.md`: prioritet og leverancer.
- `03-USE-CASE-RELATIONS.md`: afhængigheder mellem use cases.
- `04-IMPLEMENTATION-ORDER.md`: overordnet leverancerækkefølge.
- `05-CROSS-CUTTING-ACCEPTANCE.md`: fælles acceptkriterier.
- `USE-CASE-TEMPLATE.md`: skabelon til nye use cases.

Nummerér aldrig eksisterende use cases om. Brug det næste ledige stabile ID.
