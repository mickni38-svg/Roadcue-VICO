# Release checklist

- [ ] Alle inkluderede tasks har status `Done`.
- [ ] API- og toolkontrakter er kompatible eller versioneret.
- [ ] Databaseændringer har migration og verificeret opgraderingsvej.
- [ ] Secrets findes ikke i kode, prompts eller logs.
- [ ] Miljøkonfiguration er dokumenteret uden hemmelige værdier.
- [ ] Backend-, VICO- og relevante klienttests passerer.
- [ ] Kritiske integrationsflows er smoke-testet.
- [ ] Observability viser fejl uden at lække person- eller positionsdata.
- [ ] Kendte begrænsninger og rollback er dokumenteret.
