# Change checklist

- [ ] Den aktive task og use case er identificeret.
- [ ] Ændringen holder sig inden for godkendt scope.
- [ ] C#/Python/Angular-ejerskab følger arkitekturen.
- [ ] Autorisation og samtykke håndhæves i C#.
- [ ] Ingen LLM- eller Python-adgang direkte til SQL.
- [ ] Aktuelle data og præcise beregninger kommer fra tools/services.
- [ ] Kontrakt- og konfigurationsændringer er dokumenteret.
- [ ] Relevante unit-, integrations- og agenttests er kørt.
- [ ] Fejl- og usikkerhedsflows er kontrolleret.
- [ ] Tasken indeholder korte valideringsresultater.
- [ ] Varig dokumentation er kun ændret, hvis sandheden ændrede sig.
