# Review workflow

1. Læs ændringens task og linkede use case.
2. Gennemgå diffen før hele filer.
3. Kontrollér adfærd, grænser, autorisation, fejlflows og dataejerskab.
4. Sammenhold tests med acceptkriterier og de ændrede grene.
5. Rapportér fund efter alvorlighed med konkrete filhenvisninger.
6. Undlad at godkende på baggrund af “tests passerer” alene, hvis kritiske flows ikke testes.
